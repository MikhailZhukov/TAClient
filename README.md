## Features

- Browse your Tube Archivist video library with sorting and filtering
- Search across your archive
- Video playback with **H.264/H.265/AV1** (native AVPlayer) and **VP8/VP9** (VLC fallback)
- In-memory video cache with sliding window for smooth playback
- Watch progress tracking — synced with your TA server
- Channel pages with banner, description, and video list
- Threaded comment viewing
- Download queue management — add, prioritize, ignore, delete
- **Share Extension** — add YouTube videos to download queue directly from the Share sheet
- Full iPad support with landscape and multitasking
- Localization: English and Russian

## Requirements

- iOS/iPadOS 17.0+
- Xcode 26.2+
- A running [Tube Archivist](https://github.com/tubearchivist/tubearchivist) server

## Building

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/TAClient.git
   cd TAClient
   ```

2. Open `TAClient.xcodeproj` in Xcode

3. Update the signing settings:
   - Select the **TAClient** target → Signing & Capabilities → set your Team and Bundle Identifier
   - Do the same for the **ShareExtension** target
   - Update the Keychain Access Group in both entitlements files to match your new Bundle ID

4. Build and run on a simulator or device

### Command-line build

```bash
xcodebuild build -scheme TAClient -destination "platform=iOS Simulator,name=iPhone 17 Pro"
```

### Running tests

```bash
xcodebuild test -scheme TAClient -destination "platform=iOS Simulator,name=iPhone 17 Pro"
```

The project has 188 passing tests covering mappers, ViewModels, and the full data layer.
